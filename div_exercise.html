Exercício

Crie uma página HTML que inclua os seguintes elementos:

  • Um título principal (h1) com o texto "Exercício".
  • Um parágrafo (p) descrevendo o objetivo do exercício.
  • Um link (a) que redirecione para uma página externa, como "https://www.example.com".
  • Uma imagem (img) com uma fonte válida e um texto alternativo.
  • Um botão estilizado (button) com a classe "butao" que exiba o texto "Clique aqui".
  • Uma tabela (table) com pelo menos duas colunas e três linhas, contendo dados fictícios.
